Camog

This domain hosts the licence activation service for Camog, the clinical photo documentation desktop app by ClinicIQ Solutions. Camog itself runs entirely on your computer — it contacts this service once, when you activate a licence key, so the number of devices per licence can be honoured. No patient information is ever transmitted here.
